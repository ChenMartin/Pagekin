# 素材与成片阶段开发清单

以 `0.2.0-dev.12` 为基线，交付从已确认分镜到可播放样片的第一条制片流程。

- [x] **素材入库**。上传静帧、H.264 MP4 和配音，校验格式并按摘要保存。已验证 64 MiB 上限、跨作品隔离、重复上传及范围读取。
- [x] **剪辑时间线**。从确认分镜建立画面片段、字幕和配音轨。Edge 验证本机草稿及 NAS 保存，API 验证并发修订、裁剪和分镜变化后的复核。
- [x] **成片任务**。冻结时间线和素材版本，使用可选 FFmpeg 环境后台串行渲染。已验证取消、按原版本重试、竖屏 MP4 和 SRT，以及成片自带的中文字幕轨和 AAC 音轨。
- [x] **验证与交付**。Windows 与 Linux amd64 各通过 8 项常规回归，Edge 两种编辑器通过。WSL 和媒体镜像通过真实 FFmpeg 测试。Compose 验证 schema 11、22 升级至 23，恢复后保留时间线和分镜引用。中英文 README、部署说明和实施进度随 `0.2.0-dev.13` 提交。

媒体快照恢复需要 SQLite 及媒体目录。实测校验可识别缺失素材，补齐文件后可校验原素材和成片。J5005 渲染速度及 NAS 代理的上传表现留待实机验收。
