# 实施计划与验证

## 阶段 0：固定基线与完整调用链盘点

交付：锁定上游提交、非测试 Electron 导入清单、IPC 操作映射、全局活动态清单、编辑写入口清单、工作流执行归属图。阅读现有领域规格与迁移合同，记录 Web 扩展 ADR。保留上游业务测试并为跨平台适配增加契约测试。

## 阶段 1：高风险原型

优先打通：Web 启动 → 登录 → 打开作品 → 编辑一章 → 自动保存 → 另一设备读取 → AI 起草 → 关闭浏览器 → 重新进入查看候选。

门槛：

1. 在 J5005/fnOS 上通过 Docker Compose 启动 linux/amd64 镜像，实际加载和读写 SQLite/LanceDB；若向量失败，明确关闭向量并验证全文检索路径。
2. Linux 文件层通过路径越界、符号链接、目录替换、原子写入与磁盘错误测试。
3. 两个项目同时操作不共享 currentProject，后台生成不因页面切换暂停。
4. 自动保存 CAS、幂等与本地恢复闭环通过。
5. 前端关闭后完整工作流能到达预定候选状态，人工审批仍明确等待。

任一数据完整性门槛不通过，不进入真实作品迁移。若抽离成本显著超出预期，再比较按项目隔离执行进程作为过渡方案；它可隔离部分全局变量，但不能解决浏览器编排、Linux 文件层或多设备冲突。

## 阶段 2：个人可用版本

交付作品管理、设定、人物、蓝图、正文、审稿修稿、恢复候选、历史、导入导出、模型配置。完成所有可写编辑面的自动保存或明确只读/显式提交例外。登录、权限、上传与 SSE 同步不延期到最终发布才补。

## 阶段 3：移动与 NAS 加固

交付电脑/iPad/手机布局、中文输入实机验收、备份恢复、升级回滚、linux/amd64 镜像、Compose 配置与环境变量示例、健康检查、日志脱敏与磁盘告警。ARM64 不属于首版交付。PWA 安装可同期提供，完整离线作品管理后续评估。

## 阶段 4 至 6：剧本到成片

阶段 4 实现改编项目、集/场、结构化剧本、分镜与来源追踪。阶段 5 实现媒体资产、外部生成、基础多轨剪辑、worker 和成片导出。阶段 6 实现 3D 导演台、运镜参考与批量制片。详细交付和验收见 [全流程设计](06-novel-to-film.md)。

## 测试矩阵

| 层次 | 验证内容 |
| --- | --- |
| 单元/契约 | 版本 CAS、幂等摘要、上下文隔离、事件去重、输入校验 |
| 存储集成 | SQLite 事务失败回滚、数据库与事件收据一致、附件恢复、路径安全 |
| 工作流集成 | 来源变化、预算、取消、任务中断、重试不重复提交、前端退出 |
| 浏览器 | 双浏览器并发、断网、丢响应、慢网络、本地配额不足、导航中保存 |
| 实机 | iPad Safari、iPhone Safari、Android Chrome、桌面浏览器；中文输入法与软键盘 |
| NAS | J5005/fnOS、Compose 部署与重建、amd64 原生依赖、重启、磁盘满、退出宽限、代理 SSE、备份恢复 |

性能测试使用实际书库加合成大项目，分别记录正文保存延迟、长章节输入、导入峰值内存、索引耗时。验收目标先暂定局域网普通章节保存 p95 小于 1 秒（不含防抖），仅作为待测目标，不当作已经达到的性能。

## 工作量与风险

上一版 8～14 人周只能作为早期粗估。源码确认存在 Linux 文件层缺口与前端工作流迁移后，小说工作区阶段的历史预算暂列为 10～18 人周，由一名熟悉本栈的开发者实施；阶段 0/1 后重估。该范围包含开发与测试，受功能覆盖、目标 NAS、现有测试可运行性影响，不是交付承诺。

最高风险依次为：Linux 安全文件语义、工作流迁移后业务一致性、全局项目状态遗漏、自动保存与既有来源约束冲突、移动输入和后台恢复、原生依赖发布。每项都有前置原型或测试门槛，不能只依靠 UI 演示通过。

本次文档验证：核对源码路径与关键实现；新增文档相对链接做存在性检查。未执行产品测试，因为本次没有实现功能或准备运行环境。

完整制片系统的工作量需在剧本、媒体渲染和 3D 原型后重新估算，以上小说阶段估算不覆盖新增范围。
