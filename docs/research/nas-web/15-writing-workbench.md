# 小说写作 Skill 与 Web 工作台

设计基线为用户提供的 `novel-writing-skills-v3.2.1.zip`。对照 `novel-workbench` 的创作简报、叙述声音、进度、章节材料、证据审稿和方法索引。工作台沿用 Pagekin 的文档、定稿、版本校验、生成候选和阶段绑定。

| 开发项 | Web 操作 |
| --- | --- |
| 创作简报与声音 | 作品入口打开创作工作台。填写已决定的方向、写作边界、声音与认可片段，单独记录候选和待调研。可跳到最近草稿、架构、进度与 Skill 设置。 |
| 本章准备 | 蓝图和正文共用按章号保存的任务。填写视角、故事时间、人物知情和不揭示项，选用至多两项写作方法。 |
| 前文证据 | 每章最多三条唯一引句。绑定前文章号和定稿版本。来源重新定稿后，工作台标记旧引句，模型输入跳过旧引句。 |
| 审稿与修稿 | 报告显示审查范围、问题类型和引句定位。作者核对并选择意见，修订仍按差异确认。 |
| 技能包入库 | 读取九个 `SKILL.md` 入口，整理为可预览的写作提示。作者可按作品批量导入，独立绑定规划、写稿、审稿和修稿阶段。 |
| 版本与恢复 | 工作台设置有版本冲突检查。有效工作台材料计入生成来源指纹。作品 JSON 恢复时重建引句指向的文档 ID。 |

技能目录包含 `novel-workbench`、`stc-ya-adapt`、`stc-ya-beats`、`stc-ya-genre`、`stc-ya-hero`、`stc-ya-pitch`、`stc-ya-revision`、`stc-ya-series` 和 `stc-ya-toolkit`。附件提供的脚本、构建清单与参考文件用于追溯设计。运行时仅加载整理后的提示词和作者绑定的阶段。

本章材料跟随当前作品的任务。只记录在“候选方向与待调研”或“下一步与作者备注”里的内容留给作者查看。正文定稿仍通过章节操作完成。人物事实、跨章线索和前文引句沿用各自的已保存来源。

## 验证记录

- Windows 和 `linux/amd64` 容器各通过 9 项 HTTP 回归。新增用例覆盖保存冲突、作品隔离、定稿替换后引句失效、旧候选版本校验、重复导入、阶段绑定及作品 JSON 恢复。
- Edge 普通编辑器和 CodeMirror 均通过创作简报、本章方法选择和技能包导入。
- 从部署 ZIP 解包构建镜像，在独立 Compose 卷验证 `rc.1`（schema 11）和 `dev.17`（schema 26）升级至 schema 27，保留正文和历史。验证了离线启动、重启、在线备份及独立卷恢复。
- 模型调用使用模拟端点。新版本在 J5005 fnOS、iPad 和手机上的实机体验待验证。
