# Web 小说阶段任务清单

以 `0.2.0-dev.10` 为基线。按下列顺序实现、测试和修复。每项记录验证结果，最后统一更新 README、实施进度与部署说明，再提交代码和文档。

- [x] **WebDAV 定时备份**。在 NAS 配置目标目录和认证，自动上传经校验的整库快照。支持浏览器手动触发和查看结果。模拟服务验证了失败重试、重启间隔、并发防重、远端文件完整性和恢复。
- [x] **结构化架构**。四个模块均有独立字段和确认状态。现有设定可绑定，普通编辑与 AI 候选共用版本校验。已验证旧稿保留、并发修改、确认失效及作品备份恢复。
- [x] **跨章线索证据**。在埋设章、回收章的定稿查找并绑定引文，长篇进度提示缺少证据或来源已更新。已验证跨作品隔离、引文校验、重开和重新定稿、恢复副本。
- [x] **界面语言**。在浏览器切换简体中文和英文。Edge 普通编辑器和 CodeMirror 均验证了菜单、设置、保存状态及语言切换时保留当前稿件和文档位置。
- [x] **长篇与发布前回归**。500 节参考书通过排队、中断续跑和完整归纳。Windows 与 Linux amd64 回归各通过 7 项。Compose 隔离卷验证 schema 11、18 升级到 21，保留正文和历史，可独立恢复。fnOS 部署 ZIP 已解包重建镜像并通过相同容器测试。
- [x] **文档与提交**。中英文 README、Web 使用说明、发布说明和实施进度随 `0.2.0-dev.11` 提交，记录配置、迁移、回退和测试范围。

真实模型输出质量、J5005 实机资源占用和 iPad／手机中文输入属于目标环境验收。手工剧本改编已有入口，AI 改编、分镜与制片按小说到成片设计进入后续阶段。
