# 剧本与分镜阶段开发清单

以 `0.2.0-dev.11` 为基线，从同一作品的小说定稿出发，交付一集可人工确认的剧本和镜头表。

- [x] **AI 分集提案**。选择小说定稿和季集范围，预览模型输入，生成分集提纲。勾选后原子创建剧本草稿。已验证固定原文版本、重复请求去重和集号冲突回滚。
- [x] **AI 剧本候选**。用分集提纲、定稿和人物卡生成结构化场次、动作和对白。比较并采用候选，沿用手工编辑与确认。已验证剧本修订冲突、任务取消、模型输出异常和重启后的任务状态。
- [x] **分镜工作区**。从已确认的剧本版本逐场建立镜头。提供手工编辑、分场 AI 候选、排序、镜头卡视图、版本记录和导出。已验证本机草稿恢复、剧本变化后复核来源、历史导出和副本恢复。
- [x] **发布前回归与文档**。Windows 和 Linux amd64 各通过 8 项回归，Edge 普通编辑器和 CodeMirror 通过整段流程。Compose 隔离卷验证 schema 11、21 升级到 22 及独立恢复。部署 ZIP 解包重建通过。中英文 README、实施进度和部署说明随 `0.2.0-dev.12` 提交。

生成使用模拟模型验证。实际模型的分集节奏、对白质量及设备操作手感在目标环境验收。

后续制片阶段按设计实现素材版本、配音字幕、时间线与渲染，再进入 3D 导演台。 [全流程设计](06-novel-to-film.md)
