# 外部素材生成开发清单

以 `0.2.0-dev.13` 为基线，把已确认分镜、外部图像／视频／配音生成和现有素材库串起来。

- [x] **供应商配置和输入预览**。NAS 管理 Replicate 凭据与各类模型。作者确认输入后发起任务，预览与历史记录保留准确的模型参数和来源版本。
- [x] **持久化异步任务**。保存供应商任务编号，轮询、取消并在重启后接着查询。对提交结果不明确的情况要求核对，避免再次付费提交。
- [x] **结果回收和人工采用**。下载并校验限定来源的结果，保留候选，作者试听或预览后加入素材库，再用于时间线。验证跨作品隔离和整库媒体恢复。
- [x] **验证与交付**。用模拟供应商和真实媒体文件覆盖三类任务、恢复及异常。Windows 与 Linux amd64 各通过 8 项 HTTP 回归，Edge 两种编辑模式验证预览确认与采用，Compose 隔离卷验证 schema 11 和 23 升到 24。部署 ZIP 解包构建通过，README、部署说明和发布记录已更新。

真实 Replicate 账号下的模型输出、配额和费用在目标部署验收。
