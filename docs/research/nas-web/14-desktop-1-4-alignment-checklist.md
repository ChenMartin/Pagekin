# 桌面 1.4.0 对照清单

对照官方版本 `59153ce` 的发布说明与本地标签，核对 Web 小说流程。 [官方 v1.4.0](https://github.com/EthanYoQ/Pagekin/releases/tag/v1.4.0)

- [x] 正文选段增加“按意见改”。Edge 验证 `Ctrl+Enter`，HTTP 验证 2,000 字符上限、断流后恢复原意见与模型、版本变化后拒绝应用，以及作品备份保留意见和续跑关系。
- [x] 为规划、写稿、审稿、修稿和手动定稿人物提取设置分工模型。验证输入预览使用所选模型的预算、另一设备修改时的冲突、恢复原任务时的模型绑定及整库恢复。
- [x] 章节目录使用 SQLite 覆盖索引读取元数据。历史列表按需读取指定版本的正文，标明当前与已被替换的定稿。模拟断流验证了网络错误提示。
- [x] 蓝图候选留空时保留旧稿的“作者指导”和“章节要点”。作者原稿可导入为定稿，从最多三章开头片段生成反推候选。验证重试回执、只补架构空白、保护已有人物和蓝图、定稿来源变更及采用记录恢复。
- [x] Windows 与 Linux amd64 各通过 8 项 HTTP 回归，Edge 普通编辑器和 CodeMirror 均通过。部署 ZIP 解包构建，Compose 隔离卷验证从 `rc.1` 和 `dev.16` 升级到 schema 26、重启、在线备份及独立卷恢复。README、使用说明和研发记录已更新。

本轮模型调用使用模拟端点。整书逐章反推、自动定稿后处理和运行中心的恢复候选隐藏仍在后续范围。
