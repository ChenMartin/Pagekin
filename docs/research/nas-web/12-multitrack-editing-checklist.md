# 多轨剪辑开发清单

以 `0.2.0-dev.14` 为基线，完善确认分镜到样片的剪辑过程。

- [x] 时间线增加旁白、音乐和音效片段，支持素材裁剪、时间线定位、音量和淡入淡出。解码输出音频，验证不同频率素材的位置、混合、淡入淡出和间隔静音。验证旧配音、编辑冲突及分镜复核。
- [x] 增加独立字幕轨，可从镜头字幕复制初始字幕、设置起止时间，输出内嵌或烧录字幕并下载独立 SRT。验证中文字幕帧、跨镜字幕、无字幕输出及旧版清单。
- [x] 增加静帧的推近、拉远、向左和向右平移。解码四种效果的成片帧，确认画面随时间变化。
- [x] Windows 和 Linux amd64 各通过 8 项 HTTP 回归。Edge 普通编辑器和 CodeMirror 均验证本机草稿恢复与 NAS 保存。部署 ZIP 解包构建通过，Compose 在隔离卷验证从 schema 11 和 24 升级到 25、备份和恢复。README、部署说明和研发记录已更新。

本轮实测环境为 Windows、Ubuntu WSL 和 Linux amd64 容器。J5005 fnOS 的渲染耗时及 iPad、手机的操作体验留待目标设备验收。
