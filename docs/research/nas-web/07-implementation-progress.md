# Web 小说工作区实施进度

本页记录开发分支上的实现与验证。架构设想仍见 [系统设计](02-system-design.md) 和 [小说到成片设计](06-novel-to-film.md)。配置与使用以 [Web 工作区 README](../../../web-novel/README.md) 为准。

## 交付基线

| 范围 | 当前状态 |
| --- | --- |
| 2026-11-09 离线候选版 | `v0.1.0-rc.1` 的 amd64 镜像和部署包已构建，使用 SQLite schema 5。Linux Docker 和 Compose 的载入、启动、重启、在线备份和独立卷恢复已验证。 |
| CodeMirror | 开发分支接入 CodeMirror 6，普通编辑器仍可用于兼容排查。两种编辑模式通过 Edge 回归。 |
| 语义检索 | schema 6 增加按作品保存的参考资料索引。用户显式启动索引，可续跑成功批次之外的资料，并选中命中片段。模拟向量服务、浏览器和 Linux 容器回归通过。 |
| 写前细纲 | schema 7 保存正文任务选择的细纲。正文、作者要求和上下文一致时才允许引用；审稿不接收细纲。任务与候选历史可备份为独立副本。 |
| 结构化审稿 | 报告逐条记录问题、严重程度、引文和改法。复用正文历史保存审稿版本，可定位唯一匹配的引文并将勾选项加入修稿要求。 |
| 按段接受修订 | 已完成的修稿可分页对比，单独勾选插入、删除或替换。服务端合并选中改动，保留未选原文和合并前的版本。 |
| 批量写作 | schema 8 保存批次队列。按章号串行生成候选，暂停、失败或服务重启后可手动继续。 |

目前实现采用独立的 Node.js 服务、浏览器前端和 Web SQLite 库。它沿用了桌面项目的领域语义，并通过转换接口导入桌面作品。最初提案中共享 Electron 仓储和直接接入桌面执行器的内容仍是设计目标。

## 写前细纲流程记录

1. 对照上游的 [写前细纲合同](../../../src/shared/draft-short-outline.ts) 和 [生成正文命令](../../../src/services/workflows/commands/generate-draft.command.ts)，保留细纲与作者事实、实际前文、正文候选的边界。
2. 增加独立细纲任务，按章节版本、源资料和本次输入绑定。写稿时由作者选用细纲，正文候选需要另行确认。
3. 在原有任务历史与作品 JSON 备份中保留细纲关系。整库备份依旧适合迁移运行库；JSON 恢复时会生成独立的作品和任务 ID。
4. 更新中英文仓库首页、Web 使用说明与文档索引，区分历史候选版、当前开发源码和后续全流程设计。

## 结构化审稿流程记录

1. 对照桌面版的逐条审稿和作者确认流程，在 Web 版记录问题、引文、原因及建议改法。审稿引文必须对应实际待审正文。
2. 在创建审稿任务的事务中保存正文快照。报告读取时按任务基准版本校验引文，作品 JSON 恢复后仍能核对。格式不符的输出保留为可选中的纯文本。
3. 编辑器支持原文定位和勾选意见。当前文档与审稿版本一致时，可将所选意见加入修稿要求。修稿仍经候选预览与作者确认。

## 修稿合并流程记录

1. 按正文行对齐两份文本，保留未选部分的原始字符。连续拆段或合段可作为同一项比较。窄屏可分页浏览，勾选状态随页保留。
2. 合并复用章节版本和生成资料校验，使用事务写入正文历史和候选应用状态。相同选择可以安全重试，已应用的候选不能再次接受不同改动。

## 批量写作流程记录

1. 批次保存章节版本和通用作者要求，开始生成前重新核对章节。单章任务和批次共享一个模型执行槽位。
2. 相邻上一章候选以未定稿资料的身份进入提示词，并参与后续候选的来源校验。应用候选由作者逐章确认。
3. 暂停或重启保留部分输出和已完成候选。手动继续会重试未完成的章节，跳过期间已经编辑或定稿的章节。

## 验证与后续

结构化审稿和修稿合并均通过 Windows 本地及 `linux/amd64` 容器的 HTTP 回归，各 4 项。Edge 普通编辑器和 CodeMirror 均验证了审稿、手机窄屏跨页勾选以及合并保存。源码部署包已核对包含审稿与合并模块。

| 验收项 | 可复现的验证或下一步 |
| --- | --- |
| HTTP、迁移、模型与备份 | 在 `web-novel` 运行 `node --test smoke.test.mjs`。覆盖跨设备保存、整稿导入、语义索引、细纲与审稿、合并冲突、重试和正文历史。模型调用使用模拟端点。 |
| 浏览器 | 配置 `BROWSER_EXE` 后运行 `node browser-smoke.mjs`。覆盖中文输入、断网恢复、语义片段引用、细纲预览、审稿定位及窄屏跨页勾选修订。 |
